# Safe Drive - Rental Car Center

A complete car rental website built with React.js, featuring car booking, vehicle listings, and partner registration.

## Features

- 🚗 Car booking system with date picker
- 📅 Calendar showing available/booked dates
- 💬 WhatsApp integration
- 📱 Fully responsive design
- ✨ Smooth animations
- 🎨 Modern UI with multiple fonts
- 📍 Company location and contact info

## Tech Stack

- React 18
- React Router v6
- Bootstrap 5
- SCSS
- React DatePicker
- React Icons
